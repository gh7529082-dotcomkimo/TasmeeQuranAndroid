مشروع أندرويد: تسميع القرآن الكريم بالصوت
========================================

ماذا يحتوي المشروع؟
- تطبيق Android أصلي بلغة Kotlin.
- شاشة عربية تعرض العبارة التجريبية من آية الكرسي.
- زر استماع وإيقاف.
- طلب إذن الميكروفون.
- عرض النتائج الجزئية أثناء الكلام إذا كانت خدمة الهاتف تدعم ذلك.
- مقارنة نصية بسيطة بعد إزالة التشكيل.
- رسائل خطأ عربية عند غياب الإنترنت أو الإذن أو خدمة التعرف.

تنبيه مهم:
هذا مشروع مصدر قابل للبناء، وليس ملف APK مبنيًا ومختبرًا بعد. تعتمد ميزة الصوت على خدمة SpeechRecognizer الموجودة على جهاز أندرويد، وغالبًا تستخدم اتصالًا بخوادم بعيدة. دعم العربية المصرية/العربية قد يختلف حسب الجهاز وخدمة التعرف. المقارنة النصية ليست تقييمًا للتجويد أو حكمًا دينيًا على صحة التلاوة.

طريقة بناء APK باستخدام Android Studio:
1. نزّل وثبّت Android Studio على كمبيوتر (Windows أو Mac أو Linux).
2. فك ضغط ملف TasmeeQuranAndroid.zip.
3. من Android Studio اختر Open وافتح مجلد TasmeeQuranAndroid الذي يحتوي على settings.gradle.kts.
4. وافق على تثبيت/تنزيل مكونات Android SDK المطلوبة إذا طُلب منك، وانتظر انتهاء Gradle Sync.
5. من القائمة اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
6. عند انتهاء البناء اضغط رابط Locate في الإشعار. عادةً يكون الملف في:
   app/build/outputs/apk/debug/app-debug.apk
7. انقل app-debug.apk إلى هاتف Android وافتحه. إذا طلب الهاتف إذن تثبيت التطبيقات من هذا المصدر، لا تفعّله إلا إذا كنت واثقًا من الملف الذي بنيته بنفسك.
8. افتح التطبيق واسمح بالميكروفون. جرّب اتصال الإنترنت.

متطلبات البناء:
- Android Studio حديث.
- JDK 17.
- اتصال إنترنت أول مرة لتنزيل Gradle ومكونات SDK.
- يستخدم المشروع Android Gradle Plugin 8.7.3 وKotlin 2.0.21 وcompileSdk 35.

إذا فشل البناء:
- افتح Tools > SDK Manager وتأكد من تثبيت Android SDK Platform 35 وBuild Tools المتوافقة.
- تأكد من استخدام JDK 17 في Gradle settings.
- انسخ رسالة الخطأ كاملة لإصلاحها.

الأمان والخصوصية:
- يطلب التطبيق إذن RECORD_AUDIO ولا يسجل في الخلفية.
- نظام التعرف الافتراضي قد يرسل الصوت إلى خدمة خارجية. راجع إعدادات وسياسة خدمة التعرف على جهازك.
- لا تضع أي مفاتيح API سرية داخل التطبيق.
طريقة بناء APK من الموبايل فقط (تحتاج حساب GitHub):
1. افتح github.com في متصفح الهاتف وأنشئ حسابًا أو سجّل الدخول.
2. أنشئ مستودعًا جديدًا (New repository) باسم TasmeeQuranAndroid.
3. ارفع جميع ملفات المشروع إلى المستودع مع الحفاظ على المجلدات. تأكد من رفع مجلد .github وداخله workflows/build-apk.yml.
4. افتح تبويب Actions في المستودع. وافق على تفعيل GitHub Actions إذا ظهر طلب.
5. افتح سير العمل "Build Tasmee Quran APK"، واضغط Run workflow ثم Run workflow.
6. انتظر حتى تنتهي عملية البناء بعلامة نجاح. افتح نتيجة التشغيل، ثم نزّل Artifact باسم tasmee-quran-debug-apk.
7. فك ضغط ملف Artifact على الهاتف، ثم افتح app-debug.apk وثبّته. قد يطلب Android السماح بالتثبيت من Chrome أو تطبيق الملفات؛ لا تفعّل ذلك إلا للملف الذي بنيته بنفسك ومن مصدر تثق به.

ملاحظة: واجهة GitHub على الهاتف قد تكون صعبة؛ يمكن تفعيل "عرض إصدار سطح المكتب" من قائمة المتصفح. لا تشارك كلمة المرور أو رموز التحقق مع أي شخص.
